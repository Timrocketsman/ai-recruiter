# Нейро-обложки уровня GPT-image / Nano Banana — на нашей RTX 3090 (10.10, слово Тима)
Три.js и Cycles на CPU дают 3/5: нет гиперреализма и насыщенности. Нужна диффузионная модель на видеокарте.
**Модель:** Qwen-Image-2512 (20B, Apache-2.0 — коммерчески можно; Qwen-Image-2.1 НЕ брать — лицензия только для исследований;
FLUX.1-dev/Krea — тоже некоммерческие). Квант Q5_K_M 15 ГБ + энкодер Qwen2.5-VL fp8 9,4 ГБ — ComfyUI выгружает энкодер после чтения промпта, влезает в 24 ГБ.
**Доводка 3D:** Qwen-Image-Edit-2511 (Apache) берёт рендер Blender Cycles (композиция, свет, стекло) и дорисовывает фотореализм (denoise 0.5–0.6).
**Шаги для локальной сессии:** 1) `bash install_models.sh` (показ) → `--yes` (≈31 ГБ, ~20–40 мин); 2) ComfyUI перезапустить (ENABLE_comfy) — появятся ноды GGUF;
3) `python3 cover_gen.py ii-teper-si-ukaz-trampa` → смотреть; 4) при «хорошо» — 5 обложек из prompts.json, затем в конвейер журналиста: новая статья ИИ-рубрики → Bonsai пишет промпт по шаблону `_style` → cover_gen → проверка зрением (цвета, нет текста) → публикация.
Время на 3090: ≈40–60 с на картинку (40 шагов). Всё под `gpu.lock`, окно 8–16.
Cycles-генератор (`../cycles/`) остаётся как источник композиции для режима --edit и как резерв.
