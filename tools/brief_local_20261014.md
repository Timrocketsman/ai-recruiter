## 3. Единый вид всего, что выходит (паспорт публикации)

Одна статья = один паспорт, из него собираются ВСЕ площадки. Паспорт берётся из страницы, не из реестра:
`title` = H1; `lead` = первый `<p class="lead">`; `desc` = meta description (≤160); `cover` = `media/covers/<slug>.webp` (есть) иначе
снимок шапки `media/telegram/<slug>.png`; `author` = «Тимур Гуцев»; `rubric`; `url` с метками `?utm_source=<канал>&utm_medium=social&utm_campaign=journal`;
`plan_id` (п. 4). Голос — от первого лица Тима везде, без «редакция/мы/в статье разобрано».

| Площадка | Формат | Правила |
|---|---|---|
| Сайт | статья | как в п. 2.2; карточка = H1 + desc + обложка с alt = H1 |
| Telegram @timlabs_journal | картинка + **title** + lead + ссылка | один пост на статью; update → правка поста; без «попробуйте», без цен; Instagram* |
| ВКонтакте (агент `vk`) | тот же текст, та же картинка, ссылка с utm=vk | один пост на статью; update → `wall.edit` |
| Дзен (RSS → Синхробот) | title/desc/обложка из RSS | RSS = паспорт; при update — та же `guid`, новый `pubDate` не ставить |
| MARAFDY (`/partners/marafdy/`, своя RSS) | по договору партнёра (пн/ср/пт/вс 10:00) | те же ворота стиля; медицина — только «не является лечением»; sitemap автоматически |
| Ролики (`promo_video`) | подпись = title + первая фраза lead + ссылка | публикация 17:17 по календарю; текст — из паспорта статьи |

Проверка единого вида — расширить `tools/channel_check.py`: кроме Telegram сверять ВК (через ваш токен, `wall.get` своей группы) и
Дзен (RSS ↔ сайт) — одна таблица «площадка / пост / расхождение». Норма: 0.
